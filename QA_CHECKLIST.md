# QA checklist

## Profiles
- Progress in one profile does not alter any other profile.
- Reset affects only the selected profile.

## TTS
- Hebrew instructions use a Hebrew voice when installed on the device.
- English words/sentences use an English voice.
- Replay works.
- Reading questions do not auto-read the answer text.

## Progress
- Lesson completion persists after app restart.
- World 2 remains locked until World 1 is complete.
- Mastery values stay between 0 and 3.

## Curriculum
- 12 worlds are visible.
- Each world has 7 core lesson entries.
- Boss/checkpoint entries are clearly marked.

## Final device test
- Install APK on Android phone.
- Test all four profiles.
- Kill and reopen app; confirm progress persists.
- Test with device offline after TTS voices are installed.
